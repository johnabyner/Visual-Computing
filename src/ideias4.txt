┌───────────────────────────┐

│   CPF: 123.456.789-00     │
│   Curso: Informática      │

Nome: John Abyner

Curso: Informática

EasyOCR
bounding boxes do texto
confidence
texto reconhecido

--------------------------------------
Agora faça:

webcam
   ↓
EasyOCR
   ↓
texto detectado
   ↓
bounding box
   ↓
texto na tela

Por exemplo:

┌─────────────────────────────┐
│                             │
│  ┌───────────────────────┐  │
│  │ OPENAI                │  │
│  └───────────────────────┘  │
│                             │
└─────────────────────────────┘

Isso vai te ensinar uma coisa muito importante:

OCR não é só "chamar EasyOCR".

Você vai precisar lidar com:

resolução
crop
grayscale
threshold
iluminação
blur
tamanho do texto
confidence
